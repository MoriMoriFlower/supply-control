# SupplyControl（医薬品の供給不安を通知で受け取る）

医薬品の供給状況が変わったことを、**検索しに行かなくても通知で受け取る**ための個人開発PWAです。

## 出典と加工について

- **出典：厚生労働省「医療用医薬品の供給状況（供給状況一覧表）」**
  <https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iryou/kouhatu-iyaku/04_00003.html>
- 上記の公表xlsxを**本プロジェクトが加工**して作成しています（列の抽出、JSONへの変換、前回版との差分算出）。
- 厚生労働省が作成・公表したものではありません。**本リポジトリの内容について同省は一切関知していません。**
- 元データは[政府標準利用規約（第2.0版）/ 公共データ利用規約（第1.0版）](https://www.mhlw.go.jp/chosakuken/index.html)に基づき利用しています。

## 免責

- 本データは**元の公表資料を機械的に変換したもの**であり、変換の誤り・取得の遅れが含まれる可能性があります。
- 表示・通知される内容は「**公表資料の記載が前回版から変わった**」という事実のみを示します。
  在庫の有無、代替薬の可否、処方変更の要否について**何も判断していません**。
- **最終的な判断は、必ず厚生労働省の原本および電子添文・製造販売業者の情報で行ってください。**
- 個人が趣味で作成・運用しているものです。無保証です。

## 気になる薬リストについて

登録した薬のリストは**利用者の端末内（IndexedDB）にのみ保存**され、サーバーへは送信されません。
サーバーが配るのは「その日に変化した品目の一覧（全利用者に同じもの）」だけで、
どの薬に反応したかをサーバーは知りません。

## 構成

```
scripts/
  collect.mjs        取得 → 正規化 → 差分 → data/ へ保存（GitHub Actionsが1日2回実行）
  selftest.mjs       差分ロジックの自己テスト（外部アクセス不要）
  lib/schema.mjs     xlsxの列定義。原本の見出しを逐語で保持し、毎回突き合わせる
  lib/mhlw.mjs       ページ解析・ダウンロード・xlsx解析・検証
  lib/diff.mjs       前回版との差分
data/
  meta.json          版情報・件数・直近の差分サマリ
  items.json         品目の素性（①〜⑪）
  status.json        供給状況（⑫〜㉑）
  changes/           版ごとの差分。latest.json が最新
```

過去データは **git の履歴そのもの**です（`git log -p data/status.json`）。
厚労省は最新版1本しか公開しておらず、過去分は後から入手できないため、
このリポジトリの履歴が唯一の記録になります。

## 動かし方

```bash
npm ci
npm run collect    # 厚労省から取得して data/ を更新（変化がなければ何も書かない）
npm run selftest   # 差分ロジックの検証（ネットワーク不要）
```
